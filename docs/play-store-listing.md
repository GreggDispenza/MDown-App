## Screenshots

Play requires at least two phone screenshots; the store graphics script does
**not** fabricate these — use real ones so the listing is honest:

1. Build and install the app on a device or emulator
   (`adb install dist/android/*.apk`, or run the sideload APK artifact).
2. Capture the file picker screen and a conversion-result screen
   (`adb exec-out screencap -p > shot1.png`).
3. Upload 2–8 screenshots (9:16 portrait recommended, min edge 320 px).
